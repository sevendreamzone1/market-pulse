Connect your feed

Your credential is sent only to Upstox and held only for the connection attempt. It is never stored in the site, GitHub, local storage, or cookies. This page loads no third-party scripts.

Use your own current access token. The GitHub Actions secret cannot be read by this browser.

How it works

  1. Obtain a current access token from your Upstox developer app.
  2. Enter it here and select Connect.
  3. Keep this page open to receive quotes. Disconnect when finished.

Browser authorization depends on Upstox's CORS policy. If blocked, obtain a one-time socket URL using the official authorize endpoint and choose the second method. Never share either credential.

Authorization failed? Connect using PowerShell
  1. In your local repository, open PowerShell and run powershell -NoProfile -File .\scripts\connect_upstox.ps1.
  2. Enter your current access token at the hidden prompt. The helper calls Upstox directly and copies a one-time URL to your clipboard.
  3. Choose One-time authorized WebSocket URL above, paste, then connect immediately.
  4. Clear the clipboard afterwards: Set-Clipboard -Value "". Generate a new URL for each connection.

Run this locally without terminal recording or PowerShell transcription. Do not run it in GitHub Actions. If your system blocks the script, use Postman Desktop: send GET to https://api.upstox.com/v3/feed/market-data-feed/authorize, choose Authorization ? Bearer Token, enter your token, and add Accept: application/json. Copy only data.authorized_redirect_uri from the response into the second connection method. This avoids browser HTTP CORS; network and broker feed restrictions still apply.

One browser tab uses one broker connection. Broker connection and subscription limits apply. No orders are placed.
